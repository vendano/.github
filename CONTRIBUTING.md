# Contributing

### Overview

This repository hosts BSD 3‑Clause licensed templates for Vendano’s GitHub presence. By contributing, you agree that your contributions will be licensed under BSD 3‑Clause and that you’ve tested or validated the changes to the extent feasible for templates.

### How to contribute

- See open issues for ideas or propose changes.
- Fork this repository, create a feature/bug branch, and submit a pull request with a descriptive summary.
- In your PR, include a short description of the change, motivation, and any backward-compatibility notes.
- Ensure any added content (MD files, templates) uses consistent formatting and placeholder conventions.
- If you’re adjusting organization-wide links (website/support/privacy/terms), include a note in the PR description about the changes and where they’ll appear in downstream repos.

### Local setup and checks

- This repo is template-focused; most contributors won’t need a full local build. If you’re editing Markdown or template text, run basic linting on Markdown (your preferred rules) and verify that placeholder rendering works in downstream repos.
- If you add any workflow or code templates in the future, include basic validation steps in the PR description.
